imba for game studios

Agents that build your world, then play it.

01 / 3D asset building

Characters built in Blender, reviewed in the browser.

An agent writes the Blender scripts, models the character, textures it and renders a turntable for review. Kuker, Samodiva and the bug below came out of that loop, each kept as its own version so nothing approved is ever overwritten.

FOR STUDIOSConcept to reviewable model without blocking an artist, with every iteration kept on disk.

Point at a part. The agent knows exactly which one.

  • Pin a .blend, .glb or .gltf and it opens as a 3D view you turn, zoom and pan, with Maya and Blender style Alt controls.
  • A tap pins a note to the part under it. The note carries the part and material as Blender names them, the point in Blender axes and the camera.
  • Box, Circle and Free outline mark an area, and the note lists every part inside it.
  • All notes go back to the agent in one message, each with a picture of the spot from two angles.

03 / Playing Unity games

A bot that plays your build from the screen alone.

No SDK, no hooks in your code. The agent sets a goal, and a free vision model looks at a picture of the game and holds the keys, 0.4 to 0.7 seconds a move. The panel on the right of each film shows the goal, the agent's last verdict and every move.

FOR STUDIOSA Unity WebGL build is playable as soon as it is served, with nothing added to the game.

Your team plays it too, on a phone.

  • Any game in imba's web view gets touch controls: a stick for W, A, S and D, and Fire, Jump and Use buttons.
  • The Keys sheet maps each control to the key your game expects, and a drag turns the view.

04 / Automated game testing

Two layers: one that plans the test, one that presses the keys.

The agent writes the checklist a QA tester would: edges, walls, water, pickups, weapons, doors. It sets one goal at a time, the fast model plays it, and the agent reads the closing shot and judges. Faults land on a test report as findings.

FOR STUDIOSCollision, boundary and pickup checks on every build, with a film of each run as the evidence.

05 / Windows machines

The Windows build, live in the same window as the agent.

Add any Windows machine on your network by its address, or run Windows 11 in a container on the build server. Its screen streams into imba's web view, your clicks and typing reach it, and notes drawn on it go to the agent.

FOR STUDIOSCheck the Windows build, launcher or editor tool from any browser, without a desk next to the test PC.

A fleet of test PCs, listed in Settings.

  • Settings › System › Desktops lists each machine with its address and whether it answers right now.
  • Clicks, right clicks, drags, the scroll wheel and typed text all reach Windows, accented letters included, with Start, Esc and Task view on the key bar.
  • A machine marked view only is watched and never sent a key.
  • The demo machine boots Windows 11 from its kept disk in under a minute, and installs its app on the first start.

Where it stands today

The numbers above, with their edges.

Fast shooters are still hard.The bot reaches half its goals in the first-person shooter, and in one run it walked into the open and was killed before finding the pickup.
The bot plays browser builds.Unity WebGL games play today. A Windows game is reviewed by people over the live view, not played by the bot.
A large scene takes time to convert.The 796-frame hero story took 13 minutes to prepare for playback, once. A single frame takes about 90 seconds.
Remote screens are not encrypted.A machine outside a trusted network is reached through a VPN or an SSH tunnel to its screen-sharing port.
